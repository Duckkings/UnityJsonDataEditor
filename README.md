# UnityJsonDataEditor

数据表编辑器。

## 枚举模板支持

* 使用名为 `enum` 的模板来定义枚举集合。
* 每个模板实例表示一个枚举类型，实例中的每个参数会被强制转换成字符串，并在导出 C# 时生成枚举成员。
* 参数名称由工具自动顺序编号（0、1、2……），删除或新增参数时编号会自动重新排列，且无法手动修改。
* 编辑参数时无法引用其他模板或索引字段，确保枚举值保持独立。
* 在数据表中引用枚举类型的参数会自动显示为下拉框，并提供该枚举类型的所有值供选择。

## 列表参数

列表参数的增加、删除按钮会随行高等比例缩放，保持界面布局的一致性。

## 提交说明

本仓库默认处于工作分支，请在完成修改后执行 `git status` 确认变更，再运行 `git commit` 提交，必要时将提交推送到远程仓库以便在 GitHub 上查看。

如在远程分支未看到最新提交，可通过 `git log --oneline` 验证本地提交是否已生成，并使用 `git push` 将其同步到远程。

若需要重新提交已存在的变更，可执行以下步骤：

1. 使用 `git commit --amend` 更新最近一次提交的说明或内容，或在必要时通过 `git commit --allow-empty -m "Resubmit"` 生成新的空提交。
2. 运行 `git push --force-with-lease`（针对 amend）或 `git push`（针对新提交）将最新的提交记录推送到远程分支，使 GitHub 能够显示最新的变更。
3. 如有持续集成或代码审查，请在推送后刷新页面确认状态已更新。
